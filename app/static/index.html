🔗 接口信息

API Base URL: http://localhost:8000/v1 (点击复制)

API Key: 任意字符 / 可留空 (后端自动轮换实际密钥)

默认模型: 正在读取...

可用模型: 正在读取...

🛠️ 常用客户端配置

Cursor:

  • 在 Models 设置中添加并启用代理支持的 Gemini 模型。
  • 启用 Override OpenAI Base URL 并填写 http://localhost:8000/v1。

NextChat / LobeChat / Cherry Studio:

  • 服务商选择 OpenAI 或 自定义/OneAPI 模式。
  • 接口地址 (Base URL) 填 http://localhost:8000/v1。
  • API Key 填任意内容即可（如 sk-gemini）。

💻 终端测试指令

PowerShell (Windows):

Invoke-RestMethod -Uri http://localhost:8000/v1/chat/completions -Method Post -ContentType "application/json" -Body '{"model":"gemini-2.5-flash","messages":[{"role":"user","content":"你好"}]}'

Bash (Linux/Mac/Git Bash):

curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-2.5-flash","messages":[{"role":"user","content":"你好"}]}'
数据来自 /v1/status Key 仅显示脱敏前缀
